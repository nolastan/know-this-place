2760 Sacramento Street is a three-story building of 1923 divided into twelve condominium units, each its own parcel — lots 022 through 033 on block 0632 — numbered 1 through 12. The assessor records the same three stories against every one of the twelve, so that figure is the building's.

This page's parcel is lot 022, unit 1, so the assessed value and last sale shown below are that unit's and not the building's.

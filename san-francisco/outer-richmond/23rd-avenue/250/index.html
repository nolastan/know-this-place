Year built as surveyed1926

Alamo Elementary School, built in 1926 and later fully remodelled from a Collegiate Gothic building into a colourful Postmodern one - part of the wave of school alterations that followed the 1971 San Fernando earthquake and the seismic code changes it prompted.
